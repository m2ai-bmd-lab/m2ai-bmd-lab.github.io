Accessibility statement

How this website meets the Norwegian universal-design requirements.

This statement is a draft. The official accessibility statement will be published through uustatus.no before the site goes live.

This website aims to meet WCAG 2.1 level AA, as required for Norwegian public-sector websites. In particular:

  • All pages work with a keyboard alone, and focus is always visible.
  • Every interactive visual has an equivalent text list on the same page.
  • Equipment status is shown as text, never by colour alone.
  • Animations are turned off when your device asks for reduced motion.
  • All content can be read with JavaScript turned off.

If something does not work for you, please tell us using the email address at the bottom of this page.
